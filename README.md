# GregTech Book for NeoForge 1.20.1

Data-driven mod that provides a GregTech progression book with a tech tree, step-by-step guides, and multiblock blueprints.

This repository is a starting skeleton. It contains:
- basic mod skeleton (main mod class, item registration)
- example tech node JSONs and blueprint JSON
- example FTB Quests JSON that maps a couple of nodes to quests

Next steps I will take (if you want me to continue):
- implement the GUI (tech tree view, node detail view, and blueprint 3D preview)
- implement FTB Quests runtime integration (auto-generate quests or register tasks)
- add an in-game blueprint authoring/export tool
- expand the dataset to include the full GregTech machine list
